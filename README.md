# Implementación del Algoritmo de Dijkstra en Python

Este repositorio contiene una implementación en Python del **Algoritmo de Dijkstra**, utilizando Programación Orientada a Objetos (POO). El objetivo del algoritmo es encontrar la ruta más corta (de menor costo) entre un nodo de origen y un nodo de destino dentro de un grafo ponderado.

## 📋 Requisitos Técnicos
* **Lenguaje:** Python 3.x
* No requiere librerías externas (utiliza `heapq` de la biblioteca estándar).

## 🚀 Cómo ejecutarlo

1. Clona este repositorio o descarga el archivo `dijkstra.py`.
2. Abre una terminal y navega hasta el directorio donde guardaste el archivo.
3. Ejecuta el siguiente comando:

```bash
python dijkstra.py
